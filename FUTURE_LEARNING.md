# 🚀 Future Learning — Where to Go After This Course

This course covered React fundamentals through hooks, forms, routing, context, and Zustand-based
state management. That's a solid foundation—but the React ecosystem keeps moving. This page is a
starting point for continuing on your own once the classes are done.

---

## 🎥 Watch first

| Resource                                                                | Why watch it                                                                                                    |
| ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| **[The Documentary: The Story of React.js](https://www.youtube.com/watch?v=8pDqJVdNa44)** | Where React came from and why it's built the way it is—useful context for understanding *why*, not just *how*. |
| **[React Course for Beginners](https://www.youtube.com/watch?v=Dorf8i6lCuk)** | A free, full-length tutorial. It's a bit older, but the fundamentals it teaches are still accurate and solid—great for revisiting basics or filling gaps. |

---

## 🧭 What to learn next

| Topic                       | Resource                                                    | Why it matters                                                                                                                    |
| ---------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Server-side rendering**    | **[Next.js](https://nextjs.org/)**                              | The most widely used React framework in production. Adds routing, SSR/SSG, API routes, and image/font optimization on top of React. Learning it is the natural next step after client-side React + React Router. |
| **Server state management** | **[TanStack Query](https://tanstack.com/query/latest)**        | Replaces a lot of manual `useEffect` + `useState` data-fetching code (like we wrote in class) with caching, background refetching, retries, and request deduplication—a modern way to talk to APIs. |
| **Practice exercises**       | **[W3Schools React Exercises](https://www.w3schools.com/React/Default.ASP)** | Bite-sized exercises to drill syntax and concepts (components, props, hooks, forms) at your own pace. |
| **Curated resource list**    | **[React Resources](https://reactresources.com/)**              | A hand-picked directory of React courses, tools, libraries, and articles—good to bookmark and revisit as the ecosystem evolves. |

---

## 📌 Suggested path

1. **Rewatch fundamentals if needed** — the [free tutorial](https://www.youtube.com/watch?v=Dorf8i6lCuk) above, or re-read our class materials in this repo.
2. **Drill the basics** — work through the [W3Schools exercises](https://www.w3schools.com/React/Default.ASP) to reinforce syntax and patterns.
3. **Learn TanStack Query** — take one of your homework projects that fetches data with `useEffect`/`fetch` and refactor it to use TanStack Query instead. It'll make the benefits click fast.
4. **Learn Next.js** — take a small existing project (or start a new one) and rebuild it with Next.js to see routing, SSR, and file-based pages in action.
5. **Watch the documentary** — good context/history to watch any time, no prerequisites.

None of this needs to happen all at once—pick whichever feels most relevant to what you're building next, and come back to the rest later.
